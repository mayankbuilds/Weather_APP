# 🌦️ Responsive Weather App

A sleek, minimal, and fully responsive Weather Web Application that fetches real-time weather data using the **Visual Crossing Weather API**. The app dynamically updates the background UI and weather icons based on the current weather conditions of the searched city.

---

## 🚀 Features

- **Real-Time Data**: Fetches accurate current temperature, humidity, and wind speed.
- **Dynamic Icons**: Automatically changes weather icons (Clear, Rain, Clouds, Snow, etc.) based on the live climatic condition.
- **Robust Error Handling**: Displays a clean "Invalid city name" alert directly in the UI if the city isn't found.
- **Smooth UX**: Supports both clicking the search button and pressing the `Enter` key to fetch data.
- **Clean Slate Initial State**: The weather card stays hidden on page load and smoothly reveals itself only after a successful search.

---

## 🛠️ Tech Stack

- **Frontend**: HTML5, CSS3 (Flexbox, Linear Gradients, Custom Poppins Typography)
- **Scripting**: Vanilla JavaScript (ES6+, Async/Await, Fetch API)
- **API Engine**: Visual Crossing Weather API
